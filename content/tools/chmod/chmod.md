### مقدمه

ابزار `chmod` که مخفف عبارت **Change Mode** است، یکی از حیاتی‌ترین دستورات در لینوکس محسوب می‌شود. در سیستم‌عامل لینوکس، امنیت حرف اول را می‌زند و هر فایل یا پوشه دارای یک سطح دسترسی (Permission) است. با استفاده از ابزار `chmod` شما می‌توانید مشخص کنید که چه کسی اجازه دارد یک فایل را بخواند، در آن چیزی بنویسد، یا آن را اجرا کند.

فرض کنید یک اسکریپت نوشته‌اید که قرار است سرور را ری‌استارت کند؛ اگر این فایل دسترسی درستی نداشته باشد، هر کاربری در سیستم ممکن است آن را اجرا کند! اینجاست که `chmod` به کمک ما می‌آید.

### مفهوم دسترسی‌ها در لینوکس <a id="مفهوم-دسترسیها"></a>

قبل از اینکه از ابزار استفاده کنیم، باید بدانیم در لینوکس سه نوع دسترسی اصلی برای هر فایل یا پوشه وجود دارد:

> 1. **(Read) r**: اجازه خواندن محتوای فایل یا دیدن لیست فایل‌های یک پوشه.
> 2. **(Write) w**: اجازه ویرایش فایل یا حذف/ایجاد فایل درون یک پوشه.
> 3. **(Execute) x**: اجازه اجرای یک فایل (مثل اسکریپت‌ها یا برنامه‌ها) یا اجازه ورود به یک پوشه (با دستور `cd`).

همچنین این دسترسی‌ها برای سه گروه مختلف از کاربران تعریف می‌شوند:

- **(User) u**: کاربری که صاحب (Owner) فایل است.
- **(Group) g**: گروهی که فایل به آن‌ها تعلق دارد.
- **(Others) o**: بقیه کاربران سیستم (هر کسی به جز مالک و گروه فایل).
- **(All) a**: همه موارد بالا (تمام کاربران).

### تشخیص دسترسی‌های یک فایل <a id="تشخیص-دسترسیها"></a>

برای اینکه دسترسی‌های فعلی یک فایل را ببینید، کافیست از ابزار `ls` همراه با سوییچ `-l` استفاده کنید.

<div dir='ltr'>

```bash
$ ls -l script.sh

-rwxrw-r-- 1 arya developers  145 Aug 17 12:00 script.sh
```
</div>

بیایید بخش `-rwxrw-r--` را با هم معنی کنیم:
- حرف اول (`-`): نشان می‌دهد این یک فایل معمولی است (اگر `d` بود یعنی دایرکتوری/پوشه است).
- سه حرف اول (`rwx`): دسترسی مالک فایل (arya) است. یعنی می‌تواند بخواند، بنویسد و اجرا کند.
- سه حرف دوم (`rw-`): دسترسی گروه (developers) است. یعنی می‌توانند بخوانند و بنویسند اما اجازه اجرا ندارند.
- سه حرف سوم (`r--`): دسترسی بقیه افراد (Others) است. فقط می‌توانند فایل را بخوانند.

### تغییر دسترسی با استفاده از حروف (Symbolic Mode) <a id="روش-حروفی"></a>

این روش برای افراد تازه‌کار بسیار ساده‌تر است. شما از حروف `u`, `g`, `o`, `a` استفاده می‌کنید و با علامت‌های `+` (برای اضافه کردن دسترسی) و `-` (برای گرفتن دسترسی) و `=` (برای تنظیم دقیق دسترسی) کار را انجام می‌دهید.

**مثال ۱: دادن دسترسی اجرا به مالک فایل**
اگر یک اسکریپت دانلود کرده‌اید و اجرا نمی‌شود، باید دسترسی Execute به آن بدهید:

<div dir='ltr'>

```bash
$ chmod u+x script.sh
```
</div>

**مثال ۲: گرفتن دسترسی نوشتن از گروه و بقیه کاربران**
فرض کنید می‌خواهید فایل امن بماند و کسی نتواند آن را تغییر دهد:

<div dir='ltr'>

```bash
$ chmod go-w secret.txt
```
</div>
> در اینجا `g` و `o` در کنار هم نوشته شده‌اند که یعنی این تغییر برای هر دو گروه اعمال شود.

### تغییر دسترسی با استفاده از اعداد (Numeric Mode) <a id="روش-عددی"></a>

کاربران حرفه‌ای لینوکس از روش عددی (Octal) استفاده می‌کنند چون بسیار سریع‌تر است. در این روش هر سطح دسترسی یک ارزش عددی دارد:

> - **Read (r)** = 4
> - **Write (w)** = 2
> - **Execute (x)** = 1

با جمع کردن این اعداد، دسترسی مورد نظر ساخته می‌شود. مثلا اگر خواندن (۴) و نوشتن (۲) را بخواهیم، عدد می‌شود ۶. اگر تمام دسترسی‌ها را بخواهیم، عدد می‌شود ۷ (۴+۲+۱). 

برای دستور `chmod` شما باید ۳ عدد بنویسید (به ترتیب برای User و Group و Others).

**مثال ۱: دسترسی 755 (دسترسی استاندارد اسکریپت‌ها)**
<div dir='ltr'>

```bash
$ chmod 755 run_server.sh
```
</div>
- عدد اول (7): مالک فایل می‌تواند بخواند، بنویسد و اجرا کند (4+2+1).
- عدد دوم (5): گروه فایل فقط می‌تواند بخواند و اجرا کند (4+1).
- عدد سوم (5): بقیه افراد هم فقط می‌توانند بخوانند و اجرا کنند (4+1).

**مثال ۲: دسترسی 644 (دسترسی استاندارد فایل‌های متنی)**
<div dir='ltr'>

```bash
$ chmod 644 article.txt
```
</div>
مالک می‌خواند و می‌نویسد (6)، بقیه فقط می‌خوانند (4).

### اعمال تغییرات روی تمام فایل‌های یک پوشه (Recursive) <a id="تغییرات-بازگشتی"></a>

گاهی اوقات شما یک دایرکتوری کامل از فایل‌ها دارید و می‌خواهید دسترسی همه‌ی آن‌ها را به صورت همزمان تغییر دهید. برای این کار از سوییچ `-R` (با حروف بزرگ) استفاده کنید.

<div dir='ltr'>

```bash
$ chmod -R 755 /var/www/html/
```
</div>

> هشدار: از سوییچ `-R` با دقت استفاده کنید. به عنوان مثال اجرای `chmod -R 777 /` می‌تواند امنیت کل سیستم عامل لینوکس شما را نابود کند!

</div>
