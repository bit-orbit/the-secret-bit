### مقدمه

کلمه `ssh` مخفف **Secure Shell** است. قبل از اختراع ssh، مدیران سیستم برای وصل شدن به سرورها از پروتکلی به نام Telnet استفاده می‌کردند که هیچ‌گونه رمزنگاری روی داده‌ها انجام نمی‌داد؛ یعنی اگر کسی در شبکه به داده‌های شما گوش می‌داد (Sniffing)، می‌توانست رمز عبور شما را به راحتی به صورت متن ساده (Plain Text) ببیند!

ابزار `ssh` این مشکل را برای همیشه حل کرد. این ابزار به شما اجازه می‌دهد تا از طریق شبکه (یا اینترنت) به صورت کاملا رمزنگاری‌شده و امن، به خط فرمان (Terminal) یک کامپیوتر یا سرور دیگر متصل شوید و دقیقا طوری با آن کار کنید که انگار پشت آن نشسته‌اید.

### اتصال پایه به یک سرور <a id="اتصال-به-یک-سرور"></a>

ساده‌ترین حالت استفاده از این ابزار زمانی است که شما نام کاربری (Username) سرور مقصد و آدرس IP آن را می‌دانید.
فرمول کلی دستور به این شکل است: `ssh username@ip_address`

فرض کنید می‌خواهیم به سروری با آی‌پی `192.168.1.100` و نام کاربری `arya` متصل شویم:

<div dir='ltr'>

```bash
$ ssh arya@192.168.1.100
```
</div>

بعد از زدن این دستور، از شما رمز عبور کاربر `arya` روی آن سرور پرسیده می‌شود. 

> **نکته مهم:** وقتی در لینوکس رمز عبور را تایپ می‌کنید، هیچ کاراکتر یا ستاره‌ای `***` روی صفحه نشان داده نمی‌شود! این کاملا طبیعی است و به دلایل امنیتی طراحی شده است. رمز خود را با دقت تایپ کنید و Enter بزنید.

---

### تغییر پورت پیش‌فرض برای امنیت بیشتر <a id="تغییر-پورت"></a>

پروتکل ssh به صورت پیش‌فرض از پورت **22** برای ارتباط استفاده می‌کند. هکرها و ربات‌های مخرب در اینترنت همیشه پورت 22 سرورها را برای پیدا کردن رمزهای ضعیف اسکن (Brute-Force) می‌کنند. 
به همین دلیل، مدیران سرور حرفه‌ای معمولا پورت ssh را در سرور تغییر می‌دهند (مثلا به 2022). 

برای وصل شدن به سروری که پورت آن تغییر کرده است، باید از سوییچ `-p` استفاده کنید:

<div dir='ltr'>

```bash
$ ssh -p 2022 root@8.8.8.8
```
</div>

### اجرای مستقیم یک دستور روی سرور راه دور <a id="اجرای-مستقیم-دستور"></a>

گاهی اوقات شما فقط می‌خواهید یک دستور کوتاه را روی سرور اجرا کنید و سریعا خارج شوید، بدون اینکه نیازی باشد وارد محیط ترمینال سرور (Interactive Shell) شوید.
برای این کار کافیست دستور خود را در انتهای دستور ssh بنویسید (بهتر است دستور را در کوتیشن `' '` قرار دهید):

<div dir='ltr'>

```bash
$ ssh arya@192.168.1.100 'df -h'
```
</div>

این دستور به سرور وصل می‌شود، فضای خالی دیسک را با دستور `df -h` چک می‌کند، خروجی را در ترمینال سیستم شما چاپ کرده و فورا ارتباط را قطع می‌کند!

### احراز هویت با کلید (SSH Keys) بدون نیاز به رمزعبور <a id="احراز-هویت-با-کلید"></a>

تایپ کردن مداوم رمز عبور خسته‌کننده است. راه حل حرفه‌ای‌تر و امن‌تر استفاده از **SSH Keys** است. کلیدها شامل یک قفل (Public Key) و یک کلید واقعی (Private Key) هستند.

اگر شما کلید عمومی (Public Key) خود را یک بار به سرور بدهید، از دفعات بعد سرور شما را از روی سیستم خودتان می‌شناسد و **بدون پرسیدن رمز عبور** شما را وارد می‌کند!

**مرحله اول: ساخت کلید در سیستم خودتان**
ابتدا با دستور زیر روی سیستم شخصی خود یک جفت کلید بسازید (در تمام مراحل فقط Enter بزنید):

<div dir='ltr'>

```bash
$ ssh-keygen
```
</div>

**مرحله دوم: کپی کردن کلید در سرور**
حالا با استفاده از ابزار کمکی `ssh-copy-id`، کلید عمومی خود را به سرور منتقل کنید:

<div dir='ltr'>

```bash
$ ssh-copy-id arya@192.168.1.100
```
</div>

برای آخرین بار از شما رمز عبور خواسته می‌شود. از این به بعد اگر دستور `ssh arya@192.168.1.100` را بزنید، بدون هیچ رمزی مستقیما وارد سرور خواهید شد! امنیت بیشتر در کنار راحتی کار.

</div>
